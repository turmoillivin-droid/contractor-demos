## ⚡ How to Deploy Any Demo in 10 Seconds (Free, No Card/No Credits):
1. Open [tiiny.host](https://tiiny.host) in your browser.
2. Drag the corresponding `.zip` file from the workspace root (e.g. `ratombo-construction.zip`) into the upload box.
3. Tiiny.host will unpack `index.html` and instantly serve the full interactive website.
4. Set the site name to match the target subdomain and click Publish.
5. Send the live link via the pre-written WhatsApp pitch in [[Pipeline Tracker]]!
